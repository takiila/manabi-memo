# 授業カタログから履修を選ぶ

大学・学部・年度・学期を指定し、利用者自身のAIで公式シラバスを調べ、授業候補を大学情報Inboxへ保存します。候補一覧は履修中の講義とは別です。カタログ保存だけでは時間割・講義・初期ノートを作成しません。

## 手順

1. 大学・学部・対象年度・前期または後期を指定します。公式シラバスURLが分かれば指定します。この個人用設定は保存でき、次の依頼文作成にも使えます。
2. AI向け依頼文をコピーし、利用者が使うAIへ渡します。公式サイトの検索は、そのAIの検索機能・シラバス用プラグインが行います。検索できないAIには利用者が原資料を渡します。まなびメモ自体は大学サイトを巡回せず、クローラー・有料AI APIを内蔵しません。
3. AIが返したManabiImport JSONを貼り付けるか、ファイルで読み込み、解析します。出典・年度学期・不明点・更新前後を確認し、保存対象を選びます。解析だけでは保存されません。
4. 既定のcatalogモードで確定すると、選んだcourseをInboxの候補レコードとして保存します。同じ曜日・授業枠の代替候補も保存できます。
5. 保存済みカタログを出典collection・年度学期・曜日・授業枠で絞り込みます。時間割不明の候補も残るので、不明の条件でも確認します。絞り込みは表示だけで、候補の削除・履修登録を行いません。
6. 履修登録の選択はゼロ件から始まります。履修する候補だけ選び、講義の新規作成・更新、時間割の重なり、不明点を確認して確定します。この段階で選択した講義と初期ノートを作成し、確定した曜日・授業枠を時間割へ反映します。

従来の直接登録も、利用者が明示的にregisterモードを選んだ場合に利用できます。その場合も個別選択と確認が必要です。catalog/registerはアプリの取り込み方法であり、外部JSONへmodeを追加しません。

## 範囲と出典

時間割の空き枠からも登録できます。枠を押すと、表示中の年度・学期・曜日・授業枠に一致する保存済み候補だけを表示します。「講義を追加」では表示学期の候補をすべて表示します。候補を選ぶと教員・教室・単位・科目コード等の登録内容を表示し、「確認して時間割・ノートに登録」で確定します。選択だけでは保存しません。別年度・学期や時間割不明の候補を空き枠へ自動配置せず、候補がない場合も手入力に切り替えられます。更新・要確認・同枠競合は明示確認が必要で、既存講義を未配置へ動かさず、ノート・PDFを保持します。確認中に候補・講義が変わったら再選択してください。

カタログは確認できた科目の部分集合です。全授業の取得・全科目の履修可否・網羅性を保証しません。検索できなかった範囲、対象外の学部・学期、未公開の情報は未確認として残します。検索結果の要約だけで確定せず、大学の公式シラバス・時間割原本を参照します。sourceへ原本の資料名・URL・ページや見出し・短い原文を残し、追加の根拠や確認範囲はsummary、不明点はuncertaintiesへ記載します。

外部契約は[Manabi Import Schema v1](import-schema.md)のschema_version `1.0`を使います。1バッチは200件以下・1MB（1,048,576 bytes）以下で、超える場合は分割します。同じ情報集合には同じcollection、同じ開講科目には同じidを使います。バッチ番号をcollectionや既存idへ追加しません。別年度・別学期の開講は別項目にします。部分バッチに含まれない保存済み候補は削除されません。同じIDの更新は比較・選択・確認を通します。

年度と学期は原資料で確認します。設定した年度学期は検索条件であり、原資料の欠落を補う根拠にはなりません。現在年、入学年、「2年次後期」から年度を推測しません。年度不明ならtermをnullまたは省略し、元表記をsummaryへ残します。通年・四半期や不明な学期は前期・後期へ丸めず、履修登録時に利用者が原資料を確認して学期を手動指定します。曜日か授業枠の片方でも不明なら両方をnullまたは省略し、needs_reviewとuncertaintiesへ残します。時間割不明の科目は確認後に講義・ノートを登録でき、配置は未確定です。

## 確認と保存

選択した候補同士や既存講義との同年度学期・同曜日・同授業枠の重なりは確認対象です。アプリは同枠候補から履修科目を自動選択しません。プレビューのbaselineからInbox・講義が変わった場合は再確認が必要で、確定時にも選択対象・更新内容・要確認項目を検証します。既存講義の更新は確認を通し、既存ノート・PDFは保持します。保存済み候補の再登録もこの確認を通します。

大学・学部・年度・学期・任意のシラバスURLは、内部Inboxの任意catalogProfileとして保存します。外部Import JSONのフィールドではありません。個人用設定と候補は既存の端末保存・バックアップ・復元・任意の同期に含まれます。旧Inboxに設定がなくても利用でき、アカウント不要で端末内に保存できます。ログインだけで自動送信せず、既存の無料・offline-first運用と同期の選択・競合保護を維持します。共有カレンダーへ自動共有しません。

## 例

[架空のカタログJSON](../examples/manabi-import-catalog.json)は、2026年度後期の月曜第2枠にある代替候補2科目と、時間割不明の1科目を示します。すべて架空で、実際の大学情報を示しません。カタログ保存では3件を保持でき、履修登録で一方だけ選ぶと、その科目だけが時間割・講義・ノートへ反映されます。
