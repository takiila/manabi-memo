# 群馬大学との連携

2026-11-26 時点。対象は本人が閲覧できる情報。大学側は読み取り専用。リクエストの許可判断には、HTTPメソッドに加え、固定のホスト・パス・用途を使う。既存購読の読み取りと新規発行は別の操作として扱う。大学への設定変更、履修、登録、回答、提出、出席操作の機能は設けない。

## 実地調査で確認した取得先

| 情報 | 取得先と根拠 |

| 評価・授業情報 | 群馬大学の公開シラバス詳細。年度と時間割コードで照合する。評価配分・出席要件・単位取得条件は明示されている場合だけ保持する。 |

## 開発ブランチで利用できる範囲

- ICSファイル選択から確認画面へ進み、UIDの差分と更新履歴を既存Inboxで扱う。ファイル読取結果は本人が記録でき、最後の試行と最後の成功を別に保持する。ファイル0件は大学側の掲載有無の根拠にしない。元ファイル名・購読URL・エラーの生データは読取記録に含めない。
- 既存の群馬大学LMS購読URLをGETするサーバー用アダプターは、特定の公式エクスポート先に限定する。リダイレクトを追わず、有効な空カレンダーと失敗を区別する。模擬応答で検証済み。実際のURLの形式、到達性、対応イベントは未検証。スケジュール、個人用Inboxへの自動取り込み、通知との接続は未実装。
- 公開シラバスの取得済み詳細を、確認付きのInbox科目候補へ変換する処理を用意した。取得元URLの年度と時間割コードも照合する。公開シラバスから本人の履修・出欠は判断しない。自動取得とUIの接続は未実装。

## 次の実装境界

取得ジャーナルは情報源と範囲ごとに持つ。最新の試行・成功・失敗分類・取得期間・対象種別を別々に保存する。期間の境界が分からない取得結果は範囲未確認とする。空が確認できるのは、有効な応答が返り、確認した一覧と対象期間を特定できる場合に限る。認証切れ、部分取得、期限外、表示から消えた項目による自動削除は行わない。差分は元システムの安定IDで照合し、手動の提出・出席記録は別の根拠として保つ。

PC停止中の実行は、取得可能な既存ICSと公開資料から着手する。無料実行環境の頻度を確認し、期限・試験変更と取得停止を扱う。大学メールは補完候補。教務の当日変更は、大学の認可済みAPIなどの取得経路と十分な実行頻度が確認できるまで、自動通知で網羅したと判断できない。

ChatGPTはまなびメモの限定APIを使う。固定OAuth・PKCEの隔離試験は既存。PreviewのDB・Firebase・MCPの設定、ChatGPTの権限とコールバックを確認し、合成データで読み取りと本人確認後の書き込みを受け入れる。本番設定、大学アカウント、購読URLの発行はこの検証の対象外。
