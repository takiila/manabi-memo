# まなびメモの付箋・ToDo・カレンダー連携

既存のoffline-first保存、Firebase認証、参照のみのクラウド同期を維持する。追加契約・有料API・通知配信を導入しない。既存ChatGPT Siteは更新しない。

## 同期
既存の初回選択・revision競合検出・所有者確認を維持する。同期を有効にした端末で、画面復帰時と表示中の定期確認により他端末の変更を受け取る。保存領域の読込失敗・競合中は自動同期しない。

## 付箋とToDo
付箋に独立IDのチェック項目を保存する。本文編集ではIDを変えない。チェック項目ごとに全体ToDoへの登録を選び、解除しても本文・期限・完了状態を残す。コピーを作らず、付箋・ToDo・カレンダーから同じ項目を編集する。項目削除は30日間復元できる。付箋・授業回・講義の削除中は関連ToDoを表示しない。

全体一覧は登録済み付箋項目、直接追加の個人ToDo、既存Campus提出課題・学習タスクを集約する。科目・タグ（AND）・種類・完了状態・本文で絞り込み、期限・優先度・科目で並び替える。元の付箋と参照ページへ移動できる。授業トップにはその講義のチェック項目一覧を置き、登録も選べる。

## カレンダー
月表示に時間割、期限付きToDo、Campus課題・試験、Inboxの学年暦・大学予定、個人予定を集約する。日付のみは時刻未設定として表示し、23:59を補完しない。チェック項目の作業日時は締切と別に保存する。期限未設定のToDoはカレンダーに出さない。情報は出典を開ける。個人予定は共有カレンダーに自動送信しない。時間割は対象学期の曜日から表示し、実施確定ではなく通常時間割と明示する。授業回ごとに任意の授業日を指定でき、指定日のカレンダーから同じ授業回IDのノートを開ける。授業日は推測せず、未設定は従来どおり通常時間割だけを表示する。

## ホーム
今日やることカードは初期ON。未完了の期限切れ・今日・直近7日・優先表示項目に限定する。端末内設定でON/OFFと他のホームカードとの順番を変更できる。設定はクラウド状態に含めず、端末ごとに保持する。

## 互換性と検証
内部state版15。旧チェック項目・plannerなしは空として読み込む。不正な新データは読み込みを停止し、自動消去しない。バックアップ追加読込時のID衝突を回避する。外部Import Schema 1.0は維持。保存・復元・同期・日付精度・削除復元・二重表示・画面幅を検証する。
