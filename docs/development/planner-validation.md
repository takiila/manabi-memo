# 付箋・ToDo・統合カレンダーの確認

## 自動試験

`npm run test:all` で型、lint、旧保存形式、チェック項目、ToDo投影、期限の時差、学年暦取り込み、バックアップID衝突、同期の所有者保護、APIのrevision競合、PDF参照のみの転送を確認する。

## 画面操作

PC幅とスマートフォン幅で以下を確認する。

1. 講義トップから付箋のチェック項目を追加する。項目ごとの「全体ToDoに登録」を選ぶ。
2. 全体ToDoで完了・解除を操作し、元の付箋に同じ状態が残ることを確認する。
3. 期限を日付のみで登録し、カレンダーで「期限時刻未設定」と表示されることを確認する。
4. 個人ToDoにカンマ区切りの複数タグを入力する。AND絞り込み、期限・科目・種類・完了状態を確認する。
5. 開始・終了に時刻のある個人予定を編集する。メモだけの変更で日時が変わらず、開始のみの変更でも終了時刻が残ることを確認する。
6. 個人ToDo・予定・チェック項目を削除し、ごみ箱から復元する。
7. ホームの表示項目・表示順を変更して再読込する。別端末のホーム設定は変わらないことを確認する。
8. 大学情報Inboxで群馬大学2026年度後期の学年暦サンプルをプレビューし、確認後に取り込む。休業期間・授業曜日変更・出典を確認する。
9. 同一アカウントの2端末で同期をONにし、片側の変更を保存する。もう一方の画面復帰または表示中の定期確認で反映する。両方の変更がある場合は選択画面で停止する。
10. 同期待機中のアカウント切替で前のリクエスト・端末への保存が中止され、別アカウントのデータを反映しないことを確認する。

## 公開条件

GitHub上の実装と公開中のChatGPT Siteは別。AGENTS.mdに従い、この変更で既存Siteを自動更新しない。無料の認証・同期DBの公開設定は既存READMEの手順に従う。PDF本体は端末内に保持し、追加の有料サービスを導入しない。

11. 講義トップで授業回の日付を指定し、カレンダーから同じノートを開く。日付の変更・解除・削除済み授業回の非表示、同期後の日付保持を確認する。
12. 本文が空でチェック項目だけの付箋も、見返しの件数・本文に表示される。削除済みチェック項目は検索に含まれない。

## 週間表示・実機検証（PR #8 継続作業）

週間スケジュール（PC初期表示）、大学時間割、月表示の3モードを切り替える。表示設定は端末ごとの localStorage に記憶し、初回スマホ幅では月表示を用いる。週間スケジュールは月をまたいでも両月の予定を読み込む。大学時間割型では月〜土の5枠を表示し、試験・課題・個人予定・日時未指定の授業回は日別一覧に残す。これらは既存の月表示・予定データを置き換えない。

### PR #8 マージ前の優先チェック

1. **P0 実ブラウザー**: PC幅と390px幅で3モードを操作し、横スクロール、予定の重なり、クリック先、スクロール復帰を確認する。プレビューの認証制限がある場合は「未検証」のままにし、CI成功を実機確認の代わりにしない。
2. **P0 実端末同期**: 2端末で付箋・選択的ToDo・授業回日付・予定を編集して反映、競合時の保護、アカウント切替後に別利用者のデータが混入しないことを確認する。
3. **P0 バックアップ・復元**: データ入りの状態で保存・復元・削除復元を一通り試し、PDF参照、チェックID、授業回IDを維持する。
4. **P1 表示の仕上げ**: 予定重複時の重なり対策、端末別表示、授業枠の詳細な曜日・時限、時刻外の予定の見え方を調整する。
5. **P1 学年暦・AI取り込みの仕上げ**: 実際の学年暦を用いて曜日振替、個別休講と補講、資料の読み落としや変更時の差分・取り消しを検証する。サンプル取り込みがあることと、全年度・全パターンに対応することは別。
6. **保留**: 通知・追加の有料サービス、mainマージ、本番公開、既存ChatGPT Siteの更新。ユーザーの確認後に判断する。

### 週間表示の操作回帰

- PCで初回は「週間スケジュール」。次週・前週で月境界をまたいでも予定が消えない。
- 「大学時間割」に切り替え、5枠の授業を表示できる。日時未設定の授業回と提出課題は選択日の一覧から参照できる。
- 「月表示」に戻して従来の予定・出典・編集導線が利用できる。
- 設定したモードが同じ端末で再表示され、別端末へ表示設定が同期されない。
